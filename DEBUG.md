# Отладка чёрного экрана

Если вы видите чёрный экран при загрузке сайта, выполните следующие шаги:

## 1. Откройте консоль браузера

Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux) или `Cmd+Option+I` (Mac)

Перейдите на вкладку **Console**

## 2. Проверьте ошибки

Вы должны увидеть одно из следующих сообщений:

### ✅ Успешная загрузка:
```
✅ HTML loaded
✅ Root element: <div id="root">...</div>
HyperLink starting...
✅ App mounted successfully
```

### ❌ Ошибка загрузки:
Если видите красные ошибки, скопируйте их и проверьте раздел "Частые проблемы" ниже.

## 3. Частые проблемы

### Проблема: "Uncaught TypeError: Cannot read property 'getItem' of null"
**Решение:** LocalStorage недоступен. Попробуйте:
- Очистить кэш браузера
- Проверить настройки приватности
- Попробовать другой браузер

### Проблема: "Failed to load resource: net::ERR_FAILED"
**Решение:** Файлы не загрузились. Проверьте:
- Подключение к интернету
- Правильность путей в `dist/` (должны быть относительные пути `./assets/...`)
- Настройки GitHub Pages (должен быть включён)

### Проблема: "Uncaught Error: Minified React error"
**Решение:** React упал с ошибкой. Проверьте:
- Консоль на наличие ошибок
- ErrorBoundary должен показать детальную ошибку
- Попробуйте `npm run dev` для просмотра в режиме разработки

### Проблема: Чёрный экран без ошибок в консоли
**Решение:** CSS не загружается. Проверьте:
- Вкладка Network в DevTools
- Файл `assets/index-*.css` должен загружаться со статусом 200
- Попробуйте `Ctrl+Shift+R` для жёсткой перезагрузки

## 4. Режим разработки

Для отладки запустите локальный сервер:

```bash
npm run dev
```

Откройте `http://localhost:3000` и проверьте консоль.

## 5. Очистка данных

Если проблема в localStorage, очистите его:

```javascript
// В консоли браузера:
localStorage.clear();
sessionStorage.clear();
location.reload();
```

## 6. Проверка сборки

Убедитесь, что сборка прошла успешно:

```bash
npm run build
```

Проверьте папку `dist/`:
- `index.html` должен содержать ссылки на `./assets/...`
- `assets/` должна содержать `.js` и `.css` файлы

## 7. GitHub Pages

Если сайт развёрнут на GitHub Pages:

1. Проверьте Settings → Pages
2. Source должен быть "GitHub Actions"
3. Workflow должен завершиться успешно (зелёная галочка)
4. URL должен быть `https://USERNAME.github.io/REPO/`

## 8. Контакты

Если проблема не решена, создайте issue в репозитории с:
- Скриншотом консоли браузера
- Версией браузера
- URL сайта
- Описанием проблемы
