# 🎨 Загрузка обложек и интеграция с Supabase

## ✅ Что добавлено

### 1. Загрузка обложек треков/альбомов

**Где:** Редактор ссылок → вкладка "Основное"

**Возможности:**
- Загрузка изображений (JPG, PNG, WebP)
- Максимальный размер: 5MB
- Превью обложки перед сохранением
- Удаление обложки
- Автоматическая валидация файлов

**Как работает:**
- **С Supabase:** Изображения загружаются в Supabase Storage (бакет `covers`)
- **Без Supabase:** Изображения конвертируются в base64 и сохраняются локально

**Отображение:**
- На публичной странице ссылки обложка отображается в центре (40x40)
- Если обложки нет — показывается первая буква имени артиста

### 2. Интеграция с Supabase

**Что это:**
Supabase — это облачная база данных PostgreSQL с аутентификацией и хранилищем файлов.

**Преимущества:**
- ✅ Данные сохраняются в облаке (не теряются при очистке браузера)
- ✅ Доступ с любого устройства
- ✅ Масштабируемость
- ✅ Безопасность (RLS политики)
- ✅ Хранилище для обложек

**Что синхронизируется:**
- Пользователи
- Ссылки и их настройки
- Сервисы (стриминговые платформы)
- Клики и просмотры (аналитика)
- Обложки (в Supabase Storage)

## 🚀 Быстрый старт

### Режим 1: Без Supabase (локально)

Приложение работает из коробки без настройки Supabase:
- Данные хранятся в localStorage
- Обложки конвертируются в base64
- Подходит для демо и тестирования

```bash
npm install
npm run dev
```

### Режим 2: С Supabase (продакшен)

1. Создайте проект на [supabase.com](https://supabase.com)
2. Выполните SQL схему из `supabase/schema.sql`
3. Создайте бакет `covers` в Storage
4. Скопируйте API ключи в `.env`
5. Создайте пользователя в Authentication
6. Добавьте пользователя в таблицу `users`

Подробная инструкция: **SUPABASE_SETUP.md**

## 🎯 Как использовать

### Создание ссылки с обложкой

1. Перейдите в **Дашборд** → **Создать ссылку**
2. Во вкладке **"Основное"** нажмите **"Загрузить обложку"**
3. Выберите изображение (JPG, PNG, WebP, макс. 5MB)
4. Дождитесь загрузки
5. Заполните остальные поля
6. Нажмите **"Сохранить"**

### Просмотр публичной ссылки

1. Скопируйте ссылку из дашборда
2. Откройте в новой вкладке
3. Обложка отображается в центре страницы

## 🔧 Технические детали

### Загрузка обложек

```typescript
// src/lib/upload.ts

// Конвертация в base64 (без Supabase)
fileToBase64(file: File): Promise<string>

// Загрузка в Supabase Storage (с Supabase)
uploadCoverToSupabase(file, userId, linkId): Promise<string>

// Автоматический выбор метода
handleCoverUpload(file, userId, linkId): Promise<string>
```

### Supabase API

```typescript
// src/lib/supabaseApi.ts

// Пользователи
supabaseGetUser(userId)
supabaseCreateUser(user)
supabaseUpdateUser(user)

// Ссылки
supabaseGetUserLinks(userId)
supabaseGetLinkBySlug(slug)
supabaseCreateLink(link)
supabaseUpdateLink(link)
supabaseDeleteLink(linkId)

// Аналитика
supabaseAddClick(click)
supabaseAddView(view)
supabaseGetLinkClicks(linkId)
supabaseGetLinkViews(linkId)
```

## 📊 Структура базы данных

### Таблицы

- **users** — пользователи
- **links** — ссылки с настройками
- **link_services** — стриминговые сервисы для каждой ссылки
- **clicks** — клики по сервисам (аналитика)
- **page_views** — просмотры страниц (аналитика)

### Безопасность (RLS)

- Пользователи видят только свои данные
- Публичные ссылки видны всем
- Клики и просмотры публичны для аналитики
- Обложки доступны для чтения всем, загрузка только для авторизованных

## 🎨 UI/UX

### Превью обложки

- Размер: 132x132px в редакторе
- Размер: 160x160px на публичной странице
- Скруглённые углы: 8px (редактор), 12px (публичная)
- Object-fit: cover (изображение заполняет область)

### Индикаторы загрузки

- Кнопка "Загрузка..." во время загрузки файла
- Сообщения об ошибках (неверный формат, превышен размер)
- Предупреждение если Supabase не настроен

## 🐛 Известные ограничения

### Без Supabase

- Обложки хранятся в base64 (увеличивают размер localStorage)
- Данные теряются при очистке браузера
- Нет синхронизации между устройствами
- Рекомендуется только для демо

### С Supabase

- Требуется интернет-соединение
- Лимиты бесплатного плана:
  - 500MB хранилище
  - 1GB база данных
  - 50,000 активных пользователей
  - 500MB/месяц трафик
