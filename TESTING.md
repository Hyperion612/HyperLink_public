# 🧪 Инструкция по тестированию HyperLink

## ✅ Что было исправлено

### 1. Проблема с инициализацией demo-данных
**Было:** `seedDemoData()` создавала demo-пользователя, но не устанавливала его как `currentUser`
**Стало:** Теперь demo-пользователь автоматически устанавливается как текущий при первом запуске

### 2. Проблема с порядком инициализации
**Было:** Состояние инициализировалось до вызова `seedDemoData()`
**Стало:** `seedDemoData()` вызывается синхронно перед инициализацией состояния

### 3. Добавлено подробное логирование
Все ключевые операции теперь логируются в консоль для отладки

## 🚀 Как протестировать

### Шаг 1: Очистите localStorage
Откройте DevTools (F12) → Application → Local Storage → Очистите все данные

### Шаг 2: Откройте сайт
Перейдите на главную страницу. В консоли (F12 → Console) вы должны увидеть:
```
✅ App initialized successfully
✅ Current user loaded: demo@hyperlink.app
✅ User links loaded: 3
```

### Шаг 3: Проверьте автоматический вход
После инициализации demo-пользователь должен быть автоматически авторизован.
Перейдите на `/dashboard` - вы должны увидеть дашборд с 3 ссылками.

### Шаг 4: Проверьте вход через форму
1. Перейдите на `/login`
2. Введите: `demo@hyperlink.app` / `demo`
3. Должен произойти успешный вход и переход на `/dashboard`

### Шаг 5: Проверьте публичные ссылки
Перейдите на `/r/rassvet-single` - должна открыться публичная страница ссылки

## 🔍 Отладка

Если что-то не работает, откройте DevTools (F12) и проверьте:

### Console
- Должны быть сообщения с ✅ (успех) или ❌ (ошибка)
- Если видите ошибки - скопируйте их и покажите разработчику

### Application → Local Storage
Должны быть ключи:
- `hl_users` - список пользователей
- `hl_current_user` - текущий пользователь
- `hl_links` - список ссылок
- `hl_clicks` - клики
- `hl_views` - просмотры
- `hl_password_demo@hyperlink.app` - пароль demo-пользователя

### Network
- Все чанки должны загружаться успешно (статус 200)
- Не должно быть ошибок 404

## 📊 Ожидаемое поведение

### При первом запуске:
1. Автоматически создаётся demo-пользователь
2. Создаётся 3 тестовые ссылки
3. Генерируются тестовые клики и просмотры
4. Пользователь автоматически авторизуется

### При входе через форму:
1. Проверяется email и пароль
2. Если верно - происходит вход
3. Загружаются ссылки пользователя
4. Переход на дашборд

### При создании ссылки:
1. Открывается редактор
2. Можно настроить название, площадки, дизайн
3. После сохранения ссылка появляется в дашборде

### При просмотре публичной ссылки:
1. Определяется устройство и страна
2. Площадки сортируются по релевантности
3. Записывается просмотр и клики в аналитику

## 🐛 Если ничего не работает

1. **Очистите localStorage полностью**
   ```javascript
   localStorage.clear()
   ```

2. **Перезагрузите страницу** (Ctrl+Shift+R для жёсткой перезагрузки)

3. **Проверьте консоль на ошибки**
   - Откройте DevTools (F12)
   - Перейдите во вкладку Console
   - Скопируйте все ошибки

4. **Проверьте Network**
   - Убедитесь, что все файлы загружаются
   - Нет ли ошибок 404 или 500

5. **Проверьте версию браузера**
   - Требуется современный браузер с поддержкой ES6+
   - Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
